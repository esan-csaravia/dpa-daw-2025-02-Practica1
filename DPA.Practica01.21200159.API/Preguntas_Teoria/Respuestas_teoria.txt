b. ¿Qué diferencias notaste entre usar un controlador autogenerado y uno con 
repository? ¿Qué enfoque prefieres?
El autogenerado es mucho mas rapido y facil de implementar, sin embargo el de repository es mucho mas escalable y mantenible, prefiero el enfoque de repository que tiene su complejidad pero a largo plazo es mejor.

c. ¿Qué buenas prácticas implementaste (en código real) y por qué?
Utilice la parte del connection string en el appsettings.json para no tener datos sensibles en el codigo fuente, tambien implemente el patron repository para separar la logica de acceso a datos de la logica de negocio, esto ayuda a mantener el codigo limpio y facil de mantener.
